## Overview

- 최대 4인 멀티플레이어
	- Server Auth
	- 참여자 중 한 명이 Host가 되고, 다른 참여자들은 Client가 되는 구조
- PC와 Android 플랫폼 호환
- Overcooked2 모작
- 플레이 목표
	- 제한된 스테이지 시간 내에,
	- 가능한 한 신속히 음식을 제조해,
	- 최대한 많은 주문을 해결해,
	- 최고 점수를 획득
- 협동 모드와 경쟁 모드 존재
	- 협동은 최소 1인에서 최대 4인 플레이
	- 참여자 공통 주문 리스트를 해결해 제한 시간 내 고득점 기록하는 것이 목표
	- 경쟁은 최소 2인에서 최대 4인 플레이
	- 팀별 주문 리스트를 해결해 상대 팀보다 고득점 기록하는 것이 목표
